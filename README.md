# Projeto G2: Análise de Desmatamento e Preservação Ambiental no Brasil

## Objetivo
Este projeto investiga indicadores de desmatamento, queimadas e áreas preservadas no Brasil (2015-2024), atendendo aos requisitos da disciplina de Análise e Visualização de Dados com Python.

## Tecnologias Utilizadas
* Python (Pandas, NumPy)
* Plotly (Visualização de Dados)
* Streamlit (Dashboard Interativo)
* Statsmodels (Análise Estatística Avançada)

## Como executar o projeto localmente
1. Instale as dependências: `pip install -r requirements.txt`
2. Execute o dashboard: `python -m streamlit run app.py`

## Funcionalidades Avançadas Implementadas
* Dashboard Multipágina (Streamlit)
* Correlação Estatística (Pandas/NumPy e Regressão OLS)
